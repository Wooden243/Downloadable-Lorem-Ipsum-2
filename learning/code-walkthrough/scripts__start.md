# scripts/start.sh — 全文・逐次解説

## ① ファイル概要

カレントディレクトリをプロジェクトルートへ移してPHP開発サーバーを起動するWSL用補助スクリプト。

**場所**：`scripts/start.sh`。
**入出力と他ファイルの関係**：bashを用い、localhost:8000に開発サーバーをバインドする。

**前提知識**：set -euo pipefailで基本的なbash誤動作を減らす, dirname $0でスクリプト位置を基準にcd, execでシェルをPHPサーバープロセスへ置換。
